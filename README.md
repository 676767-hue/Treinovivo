# Treino Vivo

Personal trainer com IA: treinos, planos alimentares, alarmes de lembrete e níveis por XP.
Site estático (HTML, CSS e JavaScript), sem servidor.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `treino-vivo`).
2. Envie estes arquivos para a raiz do repositório.
3. Vá em **Settings > Pages**, em *Build and deployment* escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/treino-vivo/`.

## IA
Ao abrir o site, cole sua chave de API da Anthropic na aba Perfil. Ela fica só no seu navegador (localStorage). Nunca coloque a chave dentro dos arquivos do repositório.
